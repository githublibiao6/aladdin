
# 📜《玄墟：无妄界》个人开发路线图
**版本：1.0**  
**最后更新：2025年12月1日**  
**作者：独立开发者**

> 一款融合《模拟帝国》《饥荒》《我的世界》《星露谷物语》核心机制的硬核修仙生存沙盒游戏。  
> 核心理念：**无任务、无保护、死亡即终局、弱肉强食、自由发育**。

---

## 一、项目概述

### 1.1 游戏定位
- **类型**：单人开放世界 + 生存模拟 + 修仙角色扮演
- **平台**：PC（Windows / Linux / macOS）
- **引擎**：**Godot 4.3+**（开源、轻量、支持2D/3D）
- **美术风格**：低多边形（Low Poly） + 水墨贴图 + 暗黑氛围
- **目标体验**：玩家在无引导、高风险的世界中挣扎求存，通过隐藏、修炼、欺骗或掠夺变强。

### 1.2 核心原则
- ✅ **死亡即删除角色**（可选“魂灯”复活，但代价极高）
- ✅ **无主线任务，无新手引导**
- ✅ **世界动态运行，NPC有记忆与动机**
- ✅ **所有系统由玩家自行探索**
- ✅ **先做最小可玩原型（MVP），再迭代复杂度**

## 二、总体开发时间线（24–30个月）

| 阶段 | 名称 | 预计时长 | 关键交付物 |
|------|------|--------|-----------|
| Phase 0 | 前期准备与原型验证 | 1–2 个月 | 可玩5分钟核心循环Demo |
| Phase 1 | 生存基础系统 | 3–4 个月 | 完整单人生存机制（需求+合成+环境） |
| Phase 2 | 世界生成与探索 | 4–5 个月 | 程序化大地图 + 昼夜/天气/秘境 |
| Phase 3 | 修炼与成长系统 | 4–5 个月 | 功法 + 境界 + 技能释放 |
| Phase 4 | NPC与社会模拟 | 5–6 个月 | 行为树NPC + 声望/背叛/交易 |
| Phase 5 | 洞府建造与终局扩展 | 4–5 个月 | 自由建造 + 收徒 + 事件驱动 |
| Phase 6（可选） | 多周目与飞升 | 2–3 个月 | 转世印记 + 高维世界入口 |

> 💡 **总周期建议**：24个月（紧凑）至30个月（宽松），可并行美术资源制作。

## 三、各阶段详细开发计划

### **Phase 0：前期准备与原型验证**（Month 1–2）

#### 目标
验证“生存 + 危险 + 死亡惩罚”核心循环是否成立。

#### 功能清单
- [ ] 选定引擎（Godot 4.3+）
- [ ] 实现基础角色控制器（移动、交互、视角）
- [ ] 创建 32×32 极简地图（草地、树、石头）
- [ ] UI：生命、饥饿、灵力条
- [ ] 采集系统（砍树 → 木材）
- [ ] 合成系统（木材 → 木剑）
- [ ] 简单敌人AI（夜晚出现，巡逻+攻击）
- [ ] 死亡机制：角色数据删除，弹出“道陨”提示

#### 交付物
- 可运行 Demo（.exe 或 .pck）
- 核心玩法验证报告（是否有趣？是否紧张？）

---

### **Phase 1：生存基础系统**（Month 3–6）

#### 目标
构建完整的单人生存底层逻辑。

#### 功能清单
- [ ] **四大需求系统**：
    - 饥饿（随时间下降，食物恢复）
    - 灵力（施法消耗，打坐恢复，枯竭反噬）
    - 心魔值（杀戮/孤独增加，过高触发幻觉或走火入魔）
    - 睡眠（需安全环境，否则精神崩溃）
- [ ] **物品与背包系统**：
    - 格子制背包（16格）
    - 物品堆叠、耐久、品质（普通/灵品/玄品）
- [ ] **基础合成**：
    - 放置工作台解锁配方
    - 示例：草药 + 石锅 → 回气散
- [ ] **环境危害**：
    - 毒沼（持续掉血）
    - 雷雨（露天被雷劈）
    - 寒冷/炎热（需衣物调节）

#### 交付物
- 玩家可在小世界存活1–2游戏日
- 支持至少5种食物、3种工具、2种环境灾害

---

### **Phase 2：世界生成与探索**（Month 7–11）

#### 目标
实现可无限探索的动态修真世界。

#### 功能清单
- [ ] **Chunk-based 地形生成**：
    - 使用 OpenSimplexNoise 生成高度图
    - 支持无缝加载/卸载区块
- [ ] **生物群系系统**：
    - 凡人村（平原）、灵脉山（高海拔）、魔渊（地下洞穴）
- [ ] **昼夜与天气系统**：
    - 白天安全，夜晚妖兽出没
    - 特殊天象：灵气潮汐、血月
- [ ] **静态内容点位**：
    - 遗迹、秘境、古墓（预设场景，随机位置生成）

#### 交付物
- 可探索区域 ≥ 1km × 1km
- 至少3种生态区 + 2种特殊事件天气

---

### **Phase 3：修炼与成长系统**（Month 12–16）

#### 目标
让“变强”成为有策略、有风险的过程。

#### 功能清单
- [ ] **灵根系统**（初始随机：金木水火土 + 变异）
- [ ] **功法系统**（JSON配置）：
    - 属性需求、效果、副作用
    - 获取方式：拾取、偷窃、顿悟
- [ ] **境界系统**（9大境）：
    - 突破条件：灵气浓度 + 材料 + 心魔 < 阈值
    - 失败惩罚：跌境 or 重伤
- [ ] **技能/法术系统**：
    - 快捷键绑定
    - 示例：火球术（耗灵）、隐身符（限时）

#### 交付物
- 玩家可从凡人修炼至筑基期
- 支持至少5种功法、3种法术、2次境界突破

---

### **Phase 4：NPC与社会模拟**（Month 17–22）

#### 目标
让世界充满人性之暗与机会之光。

#### 功能清单
- [ ] **NPC行为树**：
    - 日常行为（采药、打坐、巡逻）
    - 事件响应（见杀人 → 逃跑/报官）
- [ ] **记忆与关系系统**：
    - 记录玩家行为（救/抢/杀）
    - 关系值影响对话与交易
- [ ] **声望 & 威胁度**：
    - 区域声望高 → 可接委托
    - 威胁过高 → 被围剿
- [ ] **交易系统**：
    - 明面商店 + 地下黑市（需暗号）
- [ ] **背叛事件**（随机触发）：
    - 同门偷功法、道侣卷款跑路

#### 交付物
- 至少10个有名字的NPC
- 支持3种以上互动结果（信任/敌对/利用）

---

### **Phase 5：洞府建造与终局扩展**（Month 23–27）

#### 目标
支持长期“苟道流”发育与势力萌芽。

#### 功能清单
- [ ] **自由建造系统**：
    - 网格放置：墙、门、炼丹炉、聚灵阵
    - 阵法需持续消耗灵力维持
- [ ] **洞府防御**：
    - 设置陷阱、傀儡守卫
    - 被入侵时触发战斗事件
- [ ] **收徒系统（简化）**：
    - 徒弟自动采集/修炼
    - 可能叛逃或被杀
- [ ] **事件驱动叙事**：
    - 随机事件：天降异宝、仇家上门、宗门招新
- [ ] **因果业力可视化**（UI提示）

#### 交付物
- 玩家可建造完整洞府（≥20个建筑部件）
- 支持至少3种洞府事件

---

### **Phase 6（可选）：多周目与飞升**（Month 28–30）

#### 功能清单
- [ ] **转世印记系统**：
    - 死亡后可选择转世，保留1项天赋
- [ ] **飞升之门**：
    - 渡劫成功 → 进入虚空地图（更高难度）
- [ ] **一生轶事记录**：
    - 自动生成玩家生平摘要（如“曾屠三宗”）

#### 交付物
- 支持多周目继承机制
- 飞升结局动画 + 新维度入口

## 四、技术栈与资源建议

| 模块 | 推荐方案 |
|------|--------|
| **引擎** | Godot 4.3+（GDScript） |
| **地图生成** | OpenSimplexNoise + Chunk Manager |
| **AI** | 行为树（BehaviorTree）或状态机 |
| **数据管理** | JSON 配置文件（功法/物品/NPC） |
| **美术资源** | Low Poly 模型（Kenney.nl、OpenGameArt）+ 手绘水墨贴图 |
| **音效** | Freesound.org + BFXR（法术音效） |
| **存档** | 加密 JSON（死亡即物理删除） |
| **发布平台** | itch.io（早期测试）、Steam（正式版） |

## 五、风险管理

| 风险 | 应对策略 |
|------|--------|
| 内容过载 | 严格MVP，砍除非核心功能（如多人、复杂剧情） |
| 美术瓶颈 | 早期用色块/图标，后期逐步替换 |
| AI太弱 | 先做反应式AI（看到就打），再升级 |
| 动力不足 | 每阶段发布Demo到itch.io，获取反馈激励 |
| 时间超支 | 优先保证核心循环，次要系统延后 |
